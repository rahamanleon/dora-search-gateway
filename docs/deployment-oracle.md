# Deployment Guide: Oracle Cloud Always Free (Primary Origin)

This guide walks through deploying the primary, persistent Dora Search instance on an Oracle Cloud Always Free VM.

---

## 1. Create the Always Free Compute Instance

1. Log into the [Oracle Cloud Console](https://cloud.oracle.com/).
2. Navigate to **Compute** &rarr; **Instances** &rarr; **Create instance**.
3. Configure the instance:
   - **Name**: `dora-search-primary`
   - **Image**: Ubuntu 24.04 or 22.04 LTS (Canonical Ubuntu).
   - **Shape**:
     - *Recommended*: **VM.Standard.A1.Flex** (Ampere ARM): Choose 2 to 4 OCPUs and 12GB to 24GB RAM (Always Free Eligible).
     - *Alternative*: **VM.Standard.E2.1.Micro** (AMD x86, 1GB RAM Always Free Eligible).
   - **Networking**: Assign a public IPv4 address.
   - **SSH Keys**: Upload your public SSH key.
4. Click **Create** and wait for the instance status to turn green (**Running**).

---

## 2. Configure VCN Ingress Rules (Firewall)

Oracle Cloud blocks incoming ports by default in its Virtual Cloud Network (VCN) Security Lists:

1. In the Instance details, click on the **Subnet** link under Primary VNIC.
2. Click on the **Default Security List for your VCN**.
3. Under **Ingress Rules**, click **Add Ingress Rules**:
   - **Rule 1 (HTTP)**:
     - Source CIDR: `0.0.0.0/0`
     - IP Protocol: `TCP`
     - Destination Port Range: `80`
     - Description: `Allow HTTP for Let's Encrypt ACME challenges`
   - **Rule 2 (HTTPS)**:
     - Source CIDR: `0.0.0.0/0`
     - IP Protocol: `TCP`
     - Destination Port Range: `443`
     - Description: `Allow HTTPS traffic to Caddy reverse proxy`
4. **Important**: Do **NOT** open port `8080`. SearXNG stays private on the Docker internal bridge network.

---

## 3. Deploy the Service

### Step 1: Connect to the instance
```bash
ssh -i /path/to/your/key ubuntu@<YOUR_ORACLE_PUBLIC_IP>
```

### Step 2: Clone the repository and run setup
```bash
git clone https://github.com/dora-ai/dora-search.git /opt/dora-search
cd /opt/dora-search/deployment/oracle
chmod +x setup.sh
./setup.sh
```

### Step 3: Configure `.env`
Edit `/opt/dora-search/deployment/oracle/.env`:
```bash
nano .env
```
Fill in your configuration:
```env
DOMAIN=search.yourdomain.com
ACME_EMAIL=admin@yourdomain.com
SEARXNG_SECRET=<auto-generated-32-byte-hex>
UPSTREAM_SECRET_TOKEN=<auto-generated-secret-token>
```

> **DNS Note**: Point an `A` record for `search.yourdomain.com` to `<YOUR_ORACLE_PUBLIC_IP>`. Caddy will automatically issue an HTTPS certificate via Let's Encrypt.

### Step 4: Start the Service
```bash
sudo systemctl start dora-search
sudo systemctl status dora-search
```

### Step 5: Test the Deployment
```bash
curl -H "Authorization: Bearer <YOUR_UPSTREAM_SECRET_TOKEN>" \
  "https://search.yourdomain.com/search?q=test&format=json"
```

If unauthorized requests attempt access:
```bash
curl -I "https://search.yourdomain.com/search?q=test&format=json"
# Returns HTTP/2 401 Unauthorized
```
This protects your SearXNG instance from being abused as a public open proxy.
